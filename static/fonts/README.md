# Fonts

This directory contains self-hosted webfonts for the Urgence Palestine site.

## Poppins

- **Source**: Google Fonts / Fontsource (`@fontsource/poppins`)
- **License**: SIL Open Font License 1.1 (`OFL-1.1`)
- **Files**: `poppins-400.woff2`, `poppins-500.woff2`, `poppins-600.woff2`, `poppins-700.woff2`
- **Usage**: body text, navigation, UI labels

The OFL-1.1 license allows free use, modification, and redistribution, including
for commercial purposes, as long as the font is not sold by itself.

## The Bold Font

- **Designer**: Sven Pels
- **Source files**: `the-bold-font.woff2`, `the-bold-font.ttf`
- **License**: "Free for Personal Use"
- **Commercial license**: <https://the-bold-font.com/product/the-bold-font-pro/>
- **Usage**: main headings (`h1`, `h2`, …)

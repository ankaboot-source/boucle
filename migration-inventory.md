# Migration inventory

Single source of truth for content migrated from the legacy site
`https://urgence-palestine.com` (canonical: `https://www.urgence-palestine.com`).
One line per migrated entry, mapping the legacy URL to the new content file
path under `src/content/<collection>/`. New lines append at the bottom;
existing lines are never rewritten so the file is append-only / review-friendly.

Conventions:

- The first column is the **legacy URL** (the canonical `https://www.…` form).
- The second column is the **new file path** relative to the repo root.
- The optional third column is a short note (category, image count, …).
- Lines starting with `#` are comments.

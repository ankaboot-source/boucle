Le **kit militant** rassemble toute la matière imprimable produite par le
collectif pour équiper les actions de terrain&nbsp;: affiches, tracts,
pancartes de manifestation, stickers et formulaires de prise de contact.

Tous les fichiers sources vivent dans le dossier partagé
[Kit Militant](https://drive.google.com/drive/folders/1QEVnz4_O9aegqadUHSvRuixKggtrI5QA?usp=sharing)
de notre Drive&nbsp;; les versions ci-dessous sont ré-hébergées sur le site
pour qu'elles restent accessibles même si le Drive est momentanément
indisponible.

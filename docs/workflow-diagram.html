boucle — Dev Loop Workflow

Autonomous dev loop for static sites. Four AI agents process GitLab issues through a pipeline with human gates.

Issue created / webhook
GitLab webhook triggers the dispatch pipeline.
DISPATCH routes by label
Parses webhook payload, routes to triage based on labels.
TRIAGE AGENT minimax-m3
Produces a structured analysis comment:
  • Analysis — what the issue asks for
  • Acceptance criteria — verifiable
  • Proposed approach — solutioning: files, components, patterns
  • Visual mockup — HTML preview for UI issues
  • Classification — Size S / M / L
  • Disposition — READY / NEEDS-INFO / NEEDS-SPLIT
